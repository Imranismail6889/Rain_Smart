# RainSmart 🌧️
RainSmart is a smart, interactive web application designed to help users track weather patterns, monitor rainfall data, and stay prepared for changing weather conditions.

-Features

Real-time Weather Monitoring: Check current meteorological conditions and rain forecasts.
Interactive Dashboard: Clean, user-friendly UI built with modern HTML5, CSS3, and JavaScript.
Responsive Design: Optimized for seamless usage across desktop, tablet, and mobile devices.
